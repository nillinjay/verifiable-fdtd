# Leg 36 — `M4` attribution: one `x`-refinement control

Date: 2026-10-20. Author evidence only; independent acceptance is the steward's responsibility.
Contract: `plan.md`, LEG 36. This leg runs one pre-declared experiment and reports which line of the
pre-declared decision rule fired. It does not relax the `1e-3` criterion, does not edit the solver
fork, and does not run the further experiment named in the rule's second line.

## 0. Outcome

The first line of the decision rule **did not fire**: with the entire PML-free interior refined in
`x`, the relative transmission difference is **0.005955030239867557** (`0.595503 %`) and the relative
reflection difference is **0.021931586119351094** (`2.193159 %`). Both remain far above the
registered `1e-3`.

The registered second line is the one that applies in the rule's binary structure, and its actionable
conclusion is confirmed: the residual is still above `1e-3`, so **the coarse `y` bands remain
implicated**. But the second line's stated magnitudes — “the error stays near `2.19 % / 3.86 %`” —
**did not reproduce**. The `x` refinement removed **72.79 %** of the transmission gap and **43.14 %**
of the reflection gap. The `x` metric is therefore **not exonerated** in the sense of “it contributes
nothing”: it accounts for most of the transmission gap and a large minority of the reflection gap.
That disagreement between the measured magnitudes and the pre-declared second line is itself reported
here; it is not resolved by inventing a third branch.

The driver exits **0**, `verdict=accepted`, and records the measurement. No accuracy criterion was
relaxed.

## 3. The control, and proof that it refines only `x`

The region is `[-6.74, 6.74]` micrometres on `x`, with a `0.64`-micrometre PML on each side. The
PML-free interior is therefore exactly `[-6.1, 6.1]`. One `MeshRefinement` box with centre
`(0, 0, 0)` and size `(12.2, 1e-9, 1e-9)` marks that whole interior fine on `x`; the negligible `y`
and `z` spans fall inside cells that the archive's own source and monitor boxes already keep fine, so
they move no node.

The driver builds a second, unrefined graded scene as a reference and compares realised node arrays
element by element:

| axis | reference graded node SHA-256 | `x`-refined node SHA-256 | equal |
|---|---|---|---|
| `x` | `79c0f495436e7fff32f84721bbb19f81979a9adb3221428d20d24bfe8bdaf165` | `8f1ab801b122a21c393d32294bfc7d90d93cdc57721631f4040b185c874318b8` | no, by design |
| `y` | `760f5baa7b3a0af9bd5c45e1f628222e844bb1929efa03dca41b923e33d96a58` | same | **yes** |
| `z` | `fdd3518f95a431e5acffcdafb0929b0cba9e97feb32f8d6f1f950256c6857c51` | same | **yes** |

The refined `x` axis is exactly uniform: every realised spacing is `0.02` micrometres within `1e-10`
relative roundoff. The `x` axis of the uniform case has the **same node hash**
`8f1ab801b122a21c393d32294bfc7d90d93cdc57721631f4040b185c874318b8`, so the longitudinal mesh is now
identical to the uniform case. `y` and `z` node hashes are identical to the archived graded case. The
`y` metric therefore remains exactly what it was in LEG 24; the `x` metric is the only one removed.
This is the strongest available check that the control is expressible without changing the archived
geometry: the scene builder, the region size, the boundaries, the source and the monitor rectangles
are untouched.

As an arithmetic cross-check (not an additional run), the source sits at `x = -5.18` and the near
monitor at `x = -4.54` micrometres in region coordinates. Each has an `0.08`-micrometre fine band around
it, so the coarse segment between the two fine bands spans `0.56` micrometres — the segment named in
the registered brief. The refinement covers exactly that segment, and the rest of the interior.

**Exit 55 was not triggered.** The control is expressible as a single `x` refinement without changing
the archived scene's geometry.

## 5. Which line of the decision rule fired

| line | condition | measured | fired |
|---|---|---|---:|
| first | `|ΔT|/|T| <= 1e-3` **and** `|ΔR|/|R| <= 1e-3` | `0.005955` and `0.021932` | **no** |
| second | “the error stays near `2.19 % / 3.86 %`” | `0.5955 %` and `2.1932 %` | premise **not reproduced**; second line applies by elimination |

The driver records `decision_rule_fired = "x-exonerated-y-implicated"` because the first gate failed
and the rule has only two lines. It also records the measured magnitudes and the reduction factors,
and its `decision_statement` says explicitly that the second line's registered magnitudes did not
reproduce. The scientific reading the rule was written to license — “`x` is exonerated; the coarse
`y` bands are implicated” — is only **partly** supported: the `y` bands are implicated in the
residual, but the `x` metric is **not** a negligible contributor. The next experiment named in the
rule (homogenised exterior, same graded nodes) was **not run**, as instructed.

## 8. What is not determined

- Whether the remaining `0.5955 %` / `2.1932 %` is caused by material sampling on the coarse `y`
  bands or by the `y` metric itself. The registered follow-up experiment was not run, by rule.
- How the `x` contribution decomposes further — for example, how much comes from the `0.56`-micrometre
  source-to-near segment versus the rest of the interior. A single full-interior refinement measures
  the total `x` contribution, not its parts.
- Whether the second-line label “`x` exonerated” was intended to tolerate a reduction of this size.
  The pre-declared text gives no tolerance for “stays near”, and this report does not invent one.
- No claim is made about graded adjoint accuracy, other propagation directions, other fixtures, or a
  replacement mesh policy. This leg attributes one measured gap; it does not accept `M4`'s accuracy.
