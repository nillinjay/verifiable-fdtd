Contract: `plan.md`, LEG 24. This is the registration renumbered from LEG 23; it is distinct from wave-2 W2.

## C4 — exact operator scope, and explicit refusal

The existing transverse eigensolver uses scalar spacings in its difference matrices. `WaveguideMode` likewise defines its coordinates, interpolation and power normalisation using scalar spacings. Therefore a genuinely nonuniform transverse aperture cannot be sent to that operator with nominal or averaged spacings. Extending that operator and its mode representation would require files beyond this leg's authorised fork write set.

The native mesher already retains a fine lattice around sources and monitors. This permits an exact, useful subset: a uniform source aperture with a uniform longitudinal source neighbourhood, embedded in a domain whose exterior coarsens. `allow_graded=True` enables that subset. The code reads the actual nodes through the existing `mesh.local_uniform_step` helper on both active transverse aperture axes and the three longitudinal source-neighbour cells. It passes those verified local spacings to the unchanged eigensolver. It does not solve on a surrogate grid or interpolate an eigenmode onto a graded aperture. The graded and uniform selected mode hashes are identical (`15c8b94161de677f90bba40a4895c438c8750f296f685da9c6a47d2e59cb479d`).

The new launch type records the realised longitudinal nodes. At readout it requires an actual E node and the launch's longitudinal spacing on both adjacent cells before reusing the unchanged half-cell phase correction. This replaces the old global-lattice coordinate assumption only in the opt-in path. Other detector locations are explicitly refused. Transverse plane quadrature retains the existing full-aperture uniform-sampling check. The plane executor freezes automatic refinements before replacing the public monitors by internal observations; the opt-in launch signs that same frozen Region so the existing signature integrity check remains active.

The default remains `allow_graded=False`, and only `mesh_type='graded'` is newly admitted. Explicit arbitrary-coordinate meshes are not newly admitted. If the supported source or detector uniformity checks fail, the driver records the error and exits **55**. A mutated transverse node is rejected before the eigensolver is called, and negative tests also cover coarse detector neighbours and off-node detectors. No claim is made that a nonuniform transverse eigenproblem has been implemented. The separate full-cell `prepare_modal_launch` and branch-network APIs are unchanged.
