# LEG 37 — the evidence-gap meta-check's fatal direction fires on the shipped declaration file (2026-10-20)

**Outcome in one line.** The meta-check **already** handled the case this leg was written to probe:
a test that flips exactly one shipped `evidence_absent_by_design` flag to `false` passes
immediately, with no change to `checks/test_leg27_evidence_gaps.py`'s checking logic. The gate is
stronger than the review finding (`F6`, an `R6` finding) feared; this leg adds the test that
keeps it honest, and nothing else.

## The hole

`checks/evidence_requirements.json` declares all four inventoried legs
(`leg4`, `leg11`, `leg12`, `leg15`) `evidence_absent_by_design: true`, so on the shipped data the
"needed-absent → fail" direction of the meta-check was reachable only through
`declarations=None` — the file-does-not-exist demonstration
(`checks/test_leg27_evidence_gaps.py`, `test_a_workspace_without_archive_or_declarations_is_needed_absent`).
A check whose fatal branch cannot be reached with the shipped data is one configuration edit away
from being a description rather than a gate.

## The construction

Extended `checks/test_leg27_evidence_gaps.py` (rather than adding a sibling file) with a new class
`Leg37FatalDirection`, because the construction reuses this module's own
`load_declarations`, `validate_declaration`, `evaluate`, `account_lines`, `is_fatal`, `INVENTORY`
and `EMPTY_PROBE_ROOT`; a sibling file would import all of them from here anyway.

Two tests, both additive against the branch's base (96 insertions, 0 deletions in the file for
the leg in total; no existing assertion touched;
`checks/evidence_requirements.json` untouched on disk):

1. **`test_one_shipped_flag_flipped_to_false_is_needed_absent_and_the_rest_stay_declared_absent`**
   — in memory, for each of the four legs in turn: deep-copy the shipped file
   (`json.loads(json.dumps(...))`, so the copy stays JSON-shaped), flip exactly that one flag to
   `False`, and require four things:
   - the shipped flag was `True` to begin with (a guard: if the shipped file ever changes, the
     test must be re-derived, not silently pass);
   - the flipped copy **passes `validate_declaration()`** — the fatal verdict below is the fatal
     direction, not a malformed-file dismissal;
   - `evaluate(EMPTY_PROBE_ROOT, flipped)` returns `needed-absent` for the flipped leg and
     `declared-absent` for the other three — exactly one flag carries the verdict;
   - the account names the leg (`leg27-evidence: <leg> needed-absent`) and the missing artefact
     (its `id`), and `is_fatal(evidence_rows, ())` is `True` — the exit-1 decision fires on the
     account alone, with the unclaimed-scan term deliberately empty so the causality is the flag
     flip and nothing else.

2. **`test_the_meta_check_exits_1_on_a_bare_root_with_one_flipped_flag`** — end to end on a
   **constructed root**, so the verdict cannot depend on local archives (this is the reworked
   form; see the rework section below): the subprocess runs the workspace-accounting test
   (`Leg27EvidenceGaps.test_this_workspace_accounts_for_every_needed_artefact`) inside a
   temporary root that carries the meta-check module verbatim, the shipped declaration file in
   its default location, and an empty `runs/` — twice: shipped file unchanged → exit `0`
   (every leg declared-absent), then exactly one flag flipped to `false` → exit `1`, naming
   `leg4 needed-absent` and `leg4-ladder-interface-ppw40-run`. `LEG27_DECLARATIONS` is stripped
   from the inherited environment, not passed through: the constructed root is authoritative.
   Every input the subprocess reads is tracked content or built in the temporary root, so the
   same answer comes out on a machine with archived runs and on a machine without.

## Rework round 1 — the end-to-end test borrowed the machine's state (2026-10-20)

The merge was correctly aborted on one MUST from the steward's re-check: the round-1 end-to-end
test drove the meta-check over the **real tree** and asserted exit `1` — which held in this
worktree only because it carries **no archived runs** (every leg absent, so a flipped flag
fires). On `main`, where the archives are present, every artefact is `present`, the flag is
moot, and the meta-check correctly exits `0` — the steward measured exactly that on `main` with
this branch applied: `Ran 397 tests`, `FAILED (failures=1)`, exit `1`. A test whose outcome is a
fact about the machine and not about the code is the same defect class LEG 27 exists to expose.

**The fix** replaces that one test (same class, renamed to
`test_the_meta_check_exits_1_on_a_bare_root_with_one_flipped_flag`; the flag-flip test was
already correct and is untouched). The subprocess now runs the workspace-accounting test inside
a temporary root the test constructs: the meta-check module copied verbatim, the shipped
declaration file in its default location, an empty `runs/`, and the host's
`LEG27_DECLARATIONS` stripped so no inherited override can leak in. It runs there twice —
shipped file unchanged → exit `0`, one flag flipped → exit `1` naming the leg and the missing
artefact — so the property is asserted on both sides of the flip, on inputs that are identical
on every machine. **Why the result can no longer depend on the presence of archived runs:** the
subprocess's `ROOT` is the temporary root (derived from the copied module's `__file__`), so the
real tree's `runs/` is never consulted; the constructed root carries its own empty `runs/` on
every machine.

**Proof both ways**, with real observed exits (the "archives" are the leg-27 negative-control
fixture's probe runs copied into the constructed root — no evidence was invented, and no
`runs/` was created in the repository):

| constructed root | declaration file | exit |
|---|---|---|
| bare (`runs/` empty) | shipped, unflipped | `0` |
| bare (`runs/` empty) | one flag flipped | `1` |
| archives for `leg11`/`leg12`/`leg15` present, `leg4` absent | one flag flipped | `1` |
| archives for all four legs present, `leg4` included | one flag flipped | `0` |
| archives for all four legs present, `leg4` included | shipped, unflipped | `0` |

Rows 3–5 are the archives-rich demonstration: the fatal direction still fires with archives on
the table (row 3), and presence dominates a flipped flag (row 4) — the flag declares absence as
acceptable, it cannot conjure absence, which is the semantics the review asked to keep honest.
