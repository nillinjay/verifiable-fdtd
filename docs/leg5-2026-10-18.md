## What could not be done

1. **The declaration is `declared-only`.** The archived readout records no monitor span or plane
   geometry, so a declared `plane` and `span` cannot be cross-checked against what the run actually
   did. Stop condition 1 applies: the field is marked `declared-only`, with that reason, rather than
   given an invented cross-check. Making it checkable needs the monitor geometry written into the
   readout, which is a change to the readout contract and its own registered step.
2. **Only one run declares a ledger.** Legs 1 to 4 predate the contract. Retro-fitting them would
   mean re-running them; that is not free and is not in this leg's scope.
3. **The ledger does not validate a normalisation against an external truth.** It checks that the
   normalisation is *declared* and *self-consistent with the archived config*. Whether the declared
   normalisation is the *right* one is `V1`'s and `V4`'s question, not this leg's.
4. **The exemption table is a checked artifact, not a loophole.** Each entry carries its reason, and
   a numeric key that is in neither the declaration nor the table is flagged. Adding an entry to the
   table is editing the contract, in the same commit history as everything else.
