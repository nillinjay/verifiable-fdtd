## C1 — the laws are recomputed, never stored

`src/analytic_cases.py` adds `film_tp`, `film_ts` (control only) and `slab_tm0_neff`, each with
its citation in the docstring. `scalar_law_points` computes every target from the entry's
declared inputs (index, thickness, wavelength, angle; core and cladding index). No analytic
value appears in any config; a test asserts that no `exact`/`expected`/`analytic_value` key is
present and that the law is computable from the declared inputs. Independent checks in the tests:
the film law reduces to leg 3's Airy law at normal incidence (13 places), gives `T = 1` at
`beta = m pi` and at the Brewster angle; the TM0 root satisfies the independent whole-thickness
form `tan(kappa d) = 2pq/(p^2 - q^2)`, lies between the TE0 root and the cladding line, and has
the right thin- and thick-core limits.

The leg-3 decision code is untouched: the leg-14 laws live in `SCALAR_LAWS` and are reached only
through ids in `SCALAR_IDS`.

## C2 — scope matched to the run, declared before it

Each check config (`configs/leg14-grating-zero-order.json`, `configs/leg14-slab-check.json`)
carries `scope_match` and `scope_match_reason`, written before its run:

* grating: one uniform lossless film filling the whole Bloch period; vacuum outside; source
  `Ex` with the Bloch wavevector along x (p polarisation); `lambda / period = 1.72 > 1 + sin(8.9002 deg)`,
  so only (0,0) propagates. The run confirms it: the efficiency in every other order is `0.0`.
* slab: symmetric, sharp interfaces (an on-interface Yee sample takes the mean of the two
  permittivities; no smoothing width), the selected launch is `Ey`-dominant (score `1.0`): TM; the
  slab is single-mode (`V = 1.41 < pi/2`).

`zero_order_forward_power` is **not judged**: it is an absolute power in solver reduced units,
and its normalisation is `S4`'s (the readout-definition ledger's) question. Claiming it would be
outside the law's scope.

## C3 — the tolerance floors, with basis and margin

**Grating: `0.01` absolute, discretisation-limited floor earned by leg 4** (second order on a
planar slab; the floor holds at `ppw >= 40`). This fixture runs at `ppw = 77` inside the film.
The run's own ladder agrees:

| mesh (um) | error at 8.5 deg | error at 8.9002 deg |
|---|---|---|
| 0.02 | `2.214e-03` | `2.211e-03` |
| 0.01 (fixture) | `5.502e-04` | `5.495e-04` |

Observed order `2.008`. Margin at the fixture: `18.2x`.

**Slab: `2.02e-03` absolute, discretisation-limited floor measured by this leg from the solver's
own self-convergence**, in a separate run (`20261018T132521Z-637008`, `configs/leg14-slab-floor.json`)
**which does not evaluate the law**:

| (dx, dy) um | `launch_neff` |
|---|---|
| (0.02, 0.01) | 2.058685519086 |
| (0.01, 0.005) — fixture | 2.055638886681 |
| (0.005, 0.0025) | 2.054881459693 |
| (0.0025, 0.00125) | 2.054692371516 |

Observed orders `2.008`, `2.002`. Richardson estimate of the fixture's own error `1.0094e-03`;
declared rule floor = 2 x estimate = `2.0189e-03`, rounded up to `2.02e-03`. The check then
measured `1.0095e-03`: margin `2.00x`, i.e. the error is **exactly the predicted
discretisation error**. The Richardson-extrapolated value `2.0546294613` agrees with the law
`2.0546293643` to `9.7e-08`.

**Disclosure.** During the arithmetic self-check of the new law code (before any run), the law's
value `2.0546294` was printed. The floor was then set by a pre-declared rule from self-convergence
alone, so it could not be steered to the law, but the law value had been seen. Likewise, the first
grating run (stopped, below) had printed the mesh-0.01 efficiency at 8.5 degrees before the rerun;
the grating tolerance `0.01` had been declared before both and was not changed.
