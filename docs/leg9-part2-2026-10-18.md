# Leg 9 part 2 evidence — the grating's own angle sensitivity — 2026-10-18

Run `20261018T072744Z-318448`, exit `0`, four Bloch runs (`~18` s each, `~72` s total).

## Result: the drift does not matter

Two Bloch cells, incidence `8.5` and `8.9002` degrees — the `0.4002` degree drift leg 7 measured over
`1.50`–`1.60` µm:

| incidence | zero-order efficiency |
|---|---|
| `8.5000` deg | `0.9087467385` |
| `8.9002` deg | `0.9087448909` |

**Change: `-1.85e-06` absolute, `2.03e-06` relative.** The realised separation is `0.400200` degrees.

| tolerance | value | the change is |
|---|---|---|
| analytic-case tolerance (legs 3, 4) | `1e-02` | **`5400x` inside** |
| the known unresolved readout discrepancy | `5.6e-02` | **`30000x` inside** |

**Verdict: below analytic tolerance.** This is the first of the three outcomes pre-declared in the
leg-9 registration.

The closed-form slab result from part 1 (`2.40e-03` absolute) is **not** the basis of this verdict.
The grating was measured, as criterion C2 required, and it turns out to be **three orders of
magnitude less sensitive** than the slab — the opposite of the direction I assumed when writing the
registration. Assuming the grating would be *sharper* was a guess, and it was wrong.

## What this settles

`S1`'s earnable requirement was "one registered oblique-illumination route with a stated error
bound". The error bound is now measured, it is `1.85e-06` on this fixture, and it is **smaller than
every tolerance this project uses**:

* **BFAST is not needed.** Leg 8 recommended declining it; this measurement removes the requirement
  rather than merely questioning it.
* **The per-frequency sweep is not needed either.** The cost argument about `41` runs is moot.
* The existing Bloch source stands, with the drift recorded as a **declared error bound**, which is
  what `S1` asked for.

## Limits, stated

1. **One fixture, one angle, one band.** `8.5` degrees on a binary grating of period `0.9` µm in a
   `0.6` µm slab. A different structure, or a near-grazing angle, is not covered.
2. **Zero order only.** The higher orders are evanescent at this period and wavelength, so the
   zero-order efficiency is the whole transmitted power.
3. **A shorter run than the reference project's.** `6000` steps against that project's `18000`. The
   comparison here is between two runs of identical length, so the *change* is meaningful even if the
   absolute value is not yet converged. The absolute `0.9087` should not be quoted as a result.
