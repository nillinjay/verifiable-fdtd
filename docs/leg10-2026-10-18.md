## Legitimate and not legitimate

**Taking one z slice of the 3-D epsilon is legitimate here, and only here.** The N8 scene builds
every solid as a box of full z extent, so the structure is z-invariant by construction. If a
structure varied along the invariant axis, the slice would be wrong and the reduction invalid. The
code says so at the point where it slices.

**The flux-unit trap is carried forward.** A 2-D plane carries flux per invariant length; a 3-D
plane carries flux over an area. Any absolute power carried across without conversion is wrong by a
factor of the invariant extent. Nothing in this leg compared absolute powers, which is why it did
not trip.

## `grid.wrap`, checked rather than assumed

paired comparison, which reads like a 2-D failure and is not one. This leg's 3-D arm ran, so nothing
here was refused for that reason.

### The fixed defect

The first sweep hand-built a `Region`. The validator refused it four times, and the readout
truncated the message to its first line, so **a region-level defect read like a 2-D source
refusal**. The repair was to **mirror `parity.project_for`'s parameter shape** — a `1` µm invariant
extent carrying one cell, `mesh_steps=(dx, dx, 1)`, Yee sampling, staircase interfaces, periodic
transverse faces, and a monitor with a positive transverse span. Every refusal now names the layer
that produced it.

### The false green, fixed

`leg10: passed` used to be decided by the `T`/`R` comparison alone, so it printed over a failed
section. The summary is now driven by **every** section — the comparisons, the source sweep and the
probes — and it reports the count it checked. On this run it correctly prints **`leg10: FAILED`**.

### TFSF: refused, with the reason, and it is not the dimension

Three successive refusals, all about the **box's own geometry requirements** in a small cell:

1. `the current isolated TFSF box requires PML on every active face`;
2. `Mesh must leave at least 5 cells between the PML boundaries`;
3. `leave at least two interior cells between each TFSF face and PML`;
4. `m must lie entirely inside the non-PML region` — the monitor's transverse span reached into the PML.

**None of these is a 2-D limitation.** They are the cost of fitting a TFSF box, its PML and a
full-span monitor into one small cell. The next attempt needs a cell roughly `3` times wider with
the monitor span pulled inside the interior, and that is a sizing exercise, not a research question.
**Recorded as an open gap, not as a pass.**
