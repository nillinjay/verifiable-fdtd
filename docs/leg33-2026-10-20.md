## The distinction this leg exists to preserve

A historical measurement and a current claim are different objects. The first records what a tool
printed at a time and must not be rewritten when later code changes the answer; the second tells the
owner what is true now. LEG 29's fix to `src/analytic_cases.py` changed the first object
retroactively, so leaving the record untouched would have made the second object wrong. This leg
does not re-measure anything and does not touch the code. It records the change in the right place
at the right tense.
